## Proyectos destacados

### Clínica Salud Total

Aplicación web académica desarrollada con **Django y Python** para la gestión de citas médicas.

Incluye autenticación, roles de paciente, médico y administrador, agendas médicas, consultas, operaciones CRUD y pruebas automatizadas.

🔗 [Ver proyecto](https://github.com/IISergioHidalgoII/SaludTotal)

### Angostura App

Prototipo académico de aplicación móvil educativa y turística desarrollado con **Flutter, Dart y Supabase**.

Incluye colección digital de especies, escaneo mediante códigos QR, grupos familiares, almacenamiento local y funcionalidades orientadas al funcionamiento con conectividad limitada.

🔗 [Ver proyecto](https://github.com/IISergioHidalgoII/Angostura-app-academico)

### Sistema de monitoreo ambiental

Sistema académico que integra **ESP32, aplicación Android y Firebase Realtime Database** para monitorear temperatura y humedad y controlar dispositivos de manera remota.

El proyecto combina firmware, sensores, aplicación móvil y comunicación mediante servicios en la nube.

🔗 [Ver proyecto](https://github.com/IISergioHidalgoII/monitoreo-ambiental-esp32)
